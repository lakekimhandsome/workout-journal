# 운동일지

메모 앱보다 빠르게 운동을 남기기 위한 가장 단순한 운동일지 MVP입니다.

## 원칙

- 한 화면에서 세션 생성, 운동 추가, 세트 기록, 코멘트 작성까지 끝냅니다.
- 운동을 분석하지 않습니다.
- 로그인 없이 브라우저 Local Storage에 저장합니다.
- 세트 수는 직접 입력하지 않고 `-` / `+` 버튼으로만 바꿉니다.
- 세트 `+`를 누르면 상단 휴식 타이머가 조용히 시작됩니다.

## 실행

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
```
